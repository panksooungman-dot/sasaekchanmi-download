Android 전용 · 약 59MB

  1. QR 코드 스캔휴대폰 카메라로 비춰주세요
  2. 앱 다운로드 선택파일이 내려받아집니다
  3. 설정에서 2가지를 켜기아래 설명을 따라주세요
  4. 파일 앱에서 설치설치 완료까지 약 30초
⚠️ ‘허용’만 눌러서는 설치되지 않습니다.
안드로이드는 인터넷에서 받은 앱을 기본적으로 막아둡니다. 아래 2가지를 먼저 켜야 합니다.
1단계 — 보안 차단 끄기
설정 → 보안 및 개인정보 보호 → 보안 위험 자동 차단 → 끄기
이게 켜져 있으면 다음 단계의 ‘허용’ 버튼이 회색으로 눌리지 않습니다.
2단계 — 출처 허용
설정 → 애플리케이션 → 특별한 접근 → 출처를 알 수 없는 앱 설치
→ 내 파일 (또는 Chrome) → 허용
파일을 연 앱이 ‘내 파일’이면 내 파일, ‘Chrome’이면 Chrome을 허용하세요.
3단계 — 설치
파일 앱 → 내려받은 sasaekchanmi.apk 탭 → 설치
기기마다 메뉴 이름이 다릅니다.
삼성 갤럭시 보안 및 개인정보 보호 → 보안 위험 자동 차단
샤오미 개인정보 보호 → 특수 권한 → 알 수 없는 출처 설치
그 외 설정 → 앱 → 특수 접근 → 알 수 없는 앱 설치
